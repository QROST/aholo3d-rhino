# Release notes

## 0.2.0-alpha.34 — preview candidate

- Streamlined Create, Library and Render workspace with contextual result actions.
- Inline form checks and faster local history search.
- Optional per-document draft recovery and remembered safe preferences.
- Integrated World, Lux3D, Spatial, local mesh/GS tools and cloud rendering workflows.
- Simplified public documentation and a smaller runtime package.

Use the matching package asset for your platform. This candidate does not claim final native Windows or latest-interface acceptance. See [testing](testing.md).

## Upgrade note

The package is now `aholo3d-rhino`. Remove the old `aholo-rhino` installation before loading the new package. Preserve its data directory; existing document references and legacy commands remain compatible. [Installation](installation.md).
