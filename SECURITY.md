# Security

Do not post API Keys, OAuth tokens, signed asset URLs, private model files or unredacted credential-store contents in public issues.

For a security-sensitive finding, use GitHub's private **Report a vulnerability** option if it is available on this repository. If it is unavailable, open a minimal issue requesting a private reporting channel without disclosing exploit details or secrets. No support email is advertised here.

Include affected versions, impact and a minimal sanitized reproduction. Do not probe accounts or services you do not own or have permission to test.

For ordinary reproducible bugs, use [GitHub Issues](https://github.com/QROST/aholo3d-rhino/issues). Preview releases receive fixes as new versions; old versions may not be patched.
