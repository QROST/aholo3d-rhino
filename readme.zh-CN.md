# Aholo for Rhino

在 Rhino 8 中创作世界与模型、显示高斯并使用云渲染，由 **CuriousArc · qrost** 开发。

[English](readme.md) · [源码仓库](https://github.com/QROST/aholo3d-rhino)

仓库和源码目录现为 **`aholo3d-rhino`**。已发布的 Yak 包继续使用 **`aholo-rhino`**，保持原有用户的更新渠道；插件标识、命令、凭据、任务/缓存及可选 USD 运行时路径保持兼容。详见[仓库改名与兼容说明](docs/repository-rename.md)。

**0.2.0-alpha.19：本地开发候选版，尚未安装或发布。** 旧 `0.1.1-beta.2` Yak 包已按用户要求撤下。新界面和服务流程已有本地构建及模拟测试证据，真实服务行为和 Rhino 原生布局仍待验收；先前 Mac GS 验收不自动覆盖本次新增能力。CuriousArc 开发的独立集成并非 Aholo 或 McNeel 官方产品。

详见[实施进度](docs/implementation-progress.md)、[API 能力与剩余范围](docs/api-capabilities.md)、[集成验收清单](docs/integrated-acceptance.md)。

## 界面语言

默认及兜底语言为英文。插件启动时优先使用有效的 Rhino 界面语言；中文 Rhino（含简体、繁体等中文地区设置）显示简体中文，其他 Rhino 语言显示英文。仅在 Rhino 无法提供有效语言时，才读取系统界面语言。修改 Rhino 语言后请重启。

面板、命令提示、GS 诊断和已知任务错误遵循同一规则；用户提示词、名称、路径、任务 ID 和保存的状态码保持原样。未知外部或技术错误保留原文，不猜测翻译。语言选择与内嵌资源已有自动化测试，双语原生界面布局仍需手动在 Rhino 验收。

## 当前功能

- 通过文字/参考图生成世界，或使用至少 20 张照片、支持的视频重建世界。
- 接入 Lux3D 全部十种公开创作操作：模型、图像、四视图、材质、拆件、格式转换、关节动画、角色绑定和动作重定向。高级参数默认收起，各操作保留自己的草稿。
- 上传室内 PLY 执行空间理解，下载 DSL，并把墙面、门窗轮廓及定向包围盒放为一个可编辑块。
- 在统一资产库搜索、分页和下载分类型结果，浏览 World/Lux3D/空间理解云历史；最多比较三个缓存候选，支持的静态 GLB、普通多边形网格 PLY、STL、支持的 3MF、静态 OBJ/分类型 OBJ ZIP 或 USD 网格 可按构造平面/点、高度及旋转放为原生 Block，无人为顶点或面数上限。绑定/动画结果可下载，尚无 Rhino 动画播放能力。
- 保留任务历史，按原始 World/Lux3D/空间理解/渲染 ID 恢复记录；下载原始 PLY/SPZ、全景图和可用的 LOD 元数据，不猜测尚未公布的渐进加载结构。
- 将完整 3DGS PLY 放为原生块实例，在 **Aholo GS (Experimental)** 模式绘制各向异性高斯椭圆、不透明度和 SH 0–3 视角颜色。原文件与完整参数保留；已实现比例、轴向、变换和撤销逻辑，详细文档生命周期测试仍待验收。
- `AholoGsProbe` 创建离线视口试验，`AholoImportGs` 导入本地 GS，`AholoGsDiagnostics` 输出状态。`AholoImportPly` 仅作为显式中心点诊断保留。
- 上传选中的 Mesh/Brep/Extrusion 及普通嵌套块，保留基础颜色与支持的 PBR 常量，可选包含选中的矩形灯/点灯，以当前透视视口相机提交离线云渲染，下载并打开结果图。
- 可选将 Key 保存至 macOS 钥匙串或 Windows 当前用户 DPAPI；不保存时仅保留在后台进程内存。
- 持久记录提交意图和任务 ID；遇到未知结果时不自动重提，避免重复创建可能扣费的任务。

**世界模型是 3D Gaussian Splatting 数据，不是普通三角网格。** World 默认放置方式现为 GS 实验渲染。缺少完整高斯字段的 PLY 会明确报错，不会悄悄转成点云。原始 PLY/SPZ 保留；支持 PLY、SPLAT 和 SPZ v1–4（SH0–3）解码；未知格式或阶数明确报错，不丢弃系数。

这是**实验渲染器**。beta.2 在真实世界模型上出现严重内存膨胀和导航卡顿；beta.3 已替换逐高斯创建原生资源的路径。可取消的后台任务负责投影与全局深度排序；界面分小段提交网格，每批最多 2,048 个高斯，共用透明度图集和材质。批大小是传输单位，不是几何上限，保留所有可见高斯。相机变化后的准备期间显示包围盒，完整帧准备好后恢复 GS；保存 3dm 时不再为缩略图渲染 GS。见[卡顿修复](docs/gs-freeze-repair.md)及[显示稳定性修复](docs/gs-visibility-stability.md)。

用户已在本机 Apple Silicon Mac 确认红/青色测试高斯、世界彩色显示、导航改善及基础裁切交互。beta.4/beta.5 修复显示稳定性与启动错误后，用户于 2026-11-02 确认复测通过，版本定为 0.1.0。完整透明度/遮挡/排序和 Windows 表现仍待验收。透明 Rhino 对象任意交错、布局细节、打印/视图捕获、立体视图与 Raytraced 集成尚不支持。显示 RGB 为 8 位且会在混合前截断 HDR；透明度使用 256 级图集，量化误差最多 0.5/255，不改变源数据。CPU 参考保留浮点数据，不能将两者说成像素完全一致。用户已观察到 Mac 基础裁切平面交互；多平面与边缘行为仍属实验范围。

实验 GS 显示现已纳入普通嵌套块。每条完整实例路径使用独立的累计变换，重复副本共享原始资产缓存；检查父对象、对象和图层的可见性，绘制时不再额外换算源单位。嵌套 GS 的代理框暂时保留，避免误隐藏同块内的普通网格。Mac／Windows 的嵌套显示、块编辑、撤销／重做仍须实机验收，见[嵌套块检查表](docs/gs-host-acceptance.md#nested-block-display-after-alpha10)。

“渲染 → 打开云预览”可为已入库的 RenderCloud 网格或 GS 资产 ID 打开独立非模态窗口，跟随原透视视口相机，显示最新 JPEG 及接收时间；导航时画面可能滞后。已实现独立本机通信通道、停止操作及持久清理记录。**这不是原生视口混合深度合成。** 公开流没有深度、alpha 或可关联相机的帧号；任意 World PLY/SPZ 到云 meshId 的入库桥接也缺少已验证的契约。完整材质网络、程序纹理和玻璃透射暂不参与云场景导出；离线流程已支持下文所述的 PBR 常量和选中矩形灯/点灯。官方当前说明世界生成主要适用于室内场景。

详见[阶段方案与依据](docs/decisions/0001-native-gaussian-viewport.md)及 [GS 验收步骤](docs/gs-host-acceptance.md)。

插件先检查并复用已有 GS 模式，在界面空闲时初始化；GS 初始化失败也不阻断主面板。若仍未就绪，可运行 `AholoGsMode` 在本机重试。0.1.0 保留已经测试的 beta.5 实现；0.1.1-beta.1 在该基础上新增本地 GS 交换，保留云任务流程；0.1.1-beta.2 新增自动界面语言选择。

## 登录、Key 与费用

官方 REST 接口目前要求在 `Authorization` 请求头使用**对应区域的原始 API Key**。Manycore OAuth 登录不能替代 World/Lux3D/RenderCloud 的这个凭据。“设置 → 账号登录（可选）”使用当前区域的官方发现、动态注册和 PKCE 浏览器授权。**在此设备记住账号登录**默认关闭；启用后将完整会话保存在 macOS 钥匙串或 Windows 当前用户 DPAPI 中，重启时仅本地恢复，不自动刷新或打开浏览器。未启用时仅在本次后台进程中保留。明确退出会移除各 Rhino 实例共用的当前区域已保存账号；关闭窗口只取消该窗口未完成的尝试。刷新需手动发起，中断或结果不明时需重新登录。这些操作不撤销服务端令牌，也不改变 API Key。生成、历史查询及渲染仍使用 Key；已实现国际区和中国区端点、独立凭据及任务归属；各区域真实账户权限和服务行为仍待验收。

区域由用户明确选择，不随语言改变。切换会撤销排队的渲染续接、停止任务轮询及实时预览，保留远端任务和另一区域保存的凭据；已获准发送的前台请求仍可能在原区域完成。旧无区域标记数据保持国际区含义。共享 API 凭据状态已升级为格式 2，旧版无法恢复；升级前请关闭旧 Rhino 实例，避免混用新旧后台进程。账号取消使用独立私有管道，不会被上传阻塞，也不会因此终止上传。

请按[官方快速开始](https://labs.aholo.ai/api-docs/en/quickstart)在 Aholo 平台创建/管理 Key，不要放进问题报告或源码。设置中可选择 World、Lux3D 或空间理解的历史查询来验证 Key，不创建任务。各服务的权限和额度独立检查。

生成和渲染可能消耗 Aholo 服务额度。点击提交按钮会启动对应流程，包括参考图或所选几何的上传、渲染前的模型解析。关闭面板或停止本地等待**不会**取消云端任务或退回额度。离线渲染的 `requestId` 只是追踪标识，**不能用来保证重复请求只扣一次费**。

## 安装

本候选版仅在本地构建，未自动安装或发布；之前的 Yak 预览版已撤下。请按下文脚本打包，审核后安装对应平台的包，并手动重启 Rhino。

1. 运行 `AholoPanel`，在右上角“设置”选择国际区或中国区，输入该区域的 Key 并选择验证服务。“验证并连接”同时应用所选区域；“应用服务区域”可恢复该区域已保存的 Key；本地 GS 导入导出和本地历史无需 Key。
2. 在“创作”选择操作，填写内容后提交一次；可选模型和输出参数位于“高级选项”。
3. 在“资产库”跟踪原任务，选择具体结果再下载；反馈显示完整保存路径，“打开结果所在文件夹”定位文件。
4. 下载支持的 GLB、网格 PLY/STL/支持的 3MF/OBJ/分类型 OBJ ZIP/USD、空间 DSL 或高斯 PLY/SPZ 后点击“放入当前文档”。网格候选按所选构造平面/点、高度及旋转放置，设置中调整 GS 单位/轴向；支持撤销，同一记录不会重复导入。可选的自动网格放置仅属于原始生成意图，关闭/切换文档或更换连接会撤销该意图。生成面数范围不用于限制导入几何。
5. 在“渲染”使用透视相机提交支持的选中几何。原会话可继续原始渲染意图；重启或连接重置后，必须明确点击继续。查询和下载不会创建新的收费请求。
6. 对已入库的云资产，可打开独立云预览窗口。启动可能消耗服务额度；停止后若清理未确认，可在清理列表重试原会话。创建响应丢失时不会自动重试创建。
7. `AholoCancel` 或底部按钮取消本地等待/准备，不取消远程任务；关闭面板保留共享后台与任务历史。

## 坐标与渲染边界

Rhino 几何使用下文所述的原始渲染网格或默认网格化，再转换为 glTF 的米/Y 向上坐标。渲染服务读取 USDA 中引用的已上传资产，不直接读取内嵌 USD 顶点数组；插件通过变换恢复渲染端要求的毫米/Z 向上坐标。**快速 GLB 入库是否完整保留这套坐标约定，还需要真实账户验证。** 首次请用已知尺寸的立方体和相机检查尺度、朝向和构图。

支持的曲面贴图使用原始渲染网格，保留各面的打包范围与旋转；缓存缺失时，按对象或文档的网格设置准备整件缓存，再逐面核对。其他路径继续使用默认网格化。源几何与分配不变，但运行时渲染缓存可能更新；失败时不会删除已有缓存。

相机保留视口水平视场角，使用所选输出图的宽高比。不支持正交相机及偏移视锥时会明确拒绝。保留平滑/自定义顶点法线（包括非均匀缩放和镜像块变换）、旧材质基础颜色以及 PBR 基色、金属度、粗糙度和 alpha 覆盖度，PBR 颜色按 Rhino 输入颜色设置预处理一次；可嵌入本地 sRGB RGB JPEG 或 RGB/RGBA PNG 基色位图，支持网格曲面 UV、Brep 原始缓存中的曲面 UV，以及材质一致且原始参数可恢复的拉伸体曲面 UV；也支持 Mesh、Brep 和拉伸体上的显式平面、盒式、圆柱和球面映射。按指定通道、通道 1、支持的曲面参数依次回退；映射变换与位图变换各应用一次，保留重复/钳制、采样和 PBR 纹理 alpha 开关，并对重复图像去重。非 sRGB、内嵌色彩配置或 EXIF 图像、缺失文件、非 Modulate 混合、程序/WCS/父级块映射、旧式通道 0、缺少原始曲面参数或拉伸体不同面材质与曲面 UV 的组合、不支持的 alpha 组合均在上传前拒绝；可主动关闭位图导出以仅使用材质常量。仅内嵌于 3DM 的位图可通过 Rhino 位图缓存解析；原生持久化与视觉一致性仍需验收。图像检查为结构校验，不等同完整 JPEG 解码或宿主视觉验收。支持将 Brep 面材质及可映射的拉伸体侧壁/端盖材质导出为独立部分，并使用有效的块父级材质。复杂材质图、玻璃透射及点云仍不支持；新增面材质行为仍需原生验收。可明确勾选导出选中的世界坐标矩形灯/点灯：矩形灯保留支持的块变换、中心及尺寸；点灯使用显式毫米球半径，再应用块缩放。非均匀缩放点灯、剪切后的非矩形灯及不支持的选中灯类型会在上传前拒绝。强度为相对倍数，未与 Rhino 流明进行光度匹配；普通嵌套块会遍历导出，不改动源几何与材质/映射分配，但可能补建运行时渲染缓存，GS 块在上传前拒绝。不支持的选中对象会报错。

3MF 放置采用独立静态网格读取器，支持核心几何、组件/变换、基础 RGBA、直接 PNG/JPEG 贴图及颜色一致的三角形颜色组。保留原始字节/哈希，复用自包含候选、块和撤销流程。渐变顶点色、镜像平铺、多层/复合材质、生产/切片及厂商扩展暂不支持。原生贴图、透明度与保存重开效果仍待验收；详见[格式边界与验收](docs/mesh-formats.md)。

## 本地网格 USD / USDZ 交换

选中模型空间的网格、曲面、拉伸体或普通嵌套块，运行 **`AholoExportMesh`**，或在“资产库”点击“导出选中网格 USD”。使用与 GS 交换相同的可选 OpenUSD 环境，不调用云服务；支持正交视图及只读文档。面板可明确关闭贴图导出，仅使用材质常量。

USDZ 是便携单文件；带贴图的 `.usd`、`.usdc`、`.usda` 会在旁边生成 `usd-assets-…` 文件夹，移动时须一起保留。覆盖场景不删除旧贴图目录，以免破坏其他文件副本的引用。转换失败或取消会保留原输出。导出使用捕获时的模型坐标，统一为毫米/Z 向上，以双精度原点和局部 float32 几何保留大坐标细节，并包含平滑法线、支持的 PBR 常量及直接 UV 贴图。普通块变换烘焙为独立网格部分，不保留可编辑块层级；贴图过滤由 USD 查看器决定，原始设置保留在元数据中。详见 [USD 交换边界](docs/usd-exchange.md)。

运行 **`AholoImportMesh`** 或通过 **资产库 → 载入本地模型** 可导入普通网格 `.usd`、`.usda`、`.usdc`、`.usdz`，进入现有候选预览、Block 和单次撤销流程。支持静态三角形/四边形和简单平面多边形、面材质子集、完整变换、法线、UV 接缝、基础 Preview Surface 材质及直接 sRGB PNG/JPEG。源文件与依赖先复制到私有快照，派生 3DM 嵌入贴图并单独保留来源哈希。可选择**按高度放到构造平面**、**原尺寸放到构造平面**或**保留场景坐标**。保留场景坐标会在换算源单位与坐标轴后维持场景位置；原尺寸和场景坐标模式支持平面网格。导入命令只载入待确认候选，不立即写入文档。

细分曲面、非平面或自交的五边及以上面、重叠或无效的材质子集、动画/蒙皮、隐藏/代理几何和不支持的着色会明确拒绝。导入展开实例层级，并按 Rhino 双面显示，原始单双面标志保留为元数据。任务中的 USD 结果已接入同一预览和直接放置流程，固定结果身份并在下载前检查放置记录；完整混合 GS/网格文件请使用 `AholoImportScene`。超过四个角点的面会保留原始角点属性进行三角化；合法的不重叠面材质分组保留最终绑定。三角形、凸平面四边形和真正非共面的四边形保留原生路径；合法的平面凹四边形保留原角点属性进行三角化。缺少法线时按 USD 语义为每个原始面生成平面法线，保留硬边；已有法线按原值保留。Rhino 原生材质、贴图持久化和 Windows 运行仍待验收。

## GS + 网格混合场景 USD 交换

运行 **`AholoExportScene`**，或在 **资产库 → 导出选中场景 USD**，可将选中的 GS 与网格、曲面、拉伸体一起导出，也支持普通嵌套块内的 GS。一次捕获选择集，保留重复实例、完整 SH 和物理位置；网格保留支持的材质与贴图。USDZ 为便携单文件，其他 USD 格式需保留旁边的贴图目录。纯 GS 或纯网格选择也可使用，不需要 API Key。目前支持静态交换，原生捕获与查看器效果仍待验收；不保留源文件的可编辑层级。单独 GS 和网格导入命令会明确拒绝混合文件。详见 [USD 交换说明](docs/usd-exchange.md)。

运行 **`AholoImportScene`** 或选择 **资产库 → 导入 USD 场景**，可完整导入静态 USD/USDA/USDC/USDZ。程序从同一份私有依赖快照读取并验证两类资产，再按源物理位置和尺寸直接放置。网格组成一个独立块，GS 保持顶层实例以供原生 GS 显示；整个操作使用一条撤销记录。单位或颜色设置变化、资产损坏会停止导入。纯 GS 和纯网格文件也可使用。此入口直接放置完整场景，与先预览再确认的本地网格候选入口不同。

离线检查可导入 [`fixtures/mixed-scene.usda`](fixtures/mixed-scene.usda)：包含红色、青色两个各向异性高斯及高度恰为 2 米的蓝色盒子。检查尺寸、旋转视角、不透明遮挡、一次撤销/重做及保存重开。Mac 和 Windows 的原生视觉、资源持久化与回滚行为仍须分别验收。

## 本地 GS USD / USDZ 导入导出

本地交换不需要 API Key，不调用网络服务。`AholoImportGs` 和面板本地导入支持完整 Gaussian PLY、32 字节 SPLAT、SPZ v1–4，以及官方 OpenUSD 静态 GS `.usd`、`.usda`、`.usdc`、`.usdz` 场景，保留多部分、完整变换、单位及向上轴；原云任务的 PLY 放置流程保留。

选中顶层 GS 块后运行 **`AholoExportGs`**，或点击面板导出。面板可明确选择选中的 GS 或全部顶层 GS；全部导出将隐藏/锁定的 GS 也作为可见资产写入。空选择及混选非 GS 对象会报错，不自动扩大导出范围。`.usdz` 是自包含便携包，`.usd`/`.usdc` 为二进制，`.usda` 为文本。保留全部高斯、SH0–3、透明度与完整对象变换，使用当前 Rhino 单位和 Z 向上。官方几何字段为 float32；双精度变换和局部原点重定位减少大坐标损失，但不能宣称任意 double 值逐位无损。导出前请设定标准长度单位。此独立 GS 通道不包含普通网格、任意厂商 GS 结构、动画及 Rhino 嵌套块；混合或嵌套导出请使用 `AholoExportScene`。

设置中的**检查 USD 运行环境**会报告本地运行时路径与版本，并显示安装命令；只有你执行该命令才会安装。

USD 功能需用 Python 3.11–3.14 安装一次独立运行时：

```sh
python3.12 scripts/setup-usd.py
python3.12 scripts/setup-usd.py --check
```

Windows 可用 `py -3.12`。脚本把固定的 `usd-core==26.11` 安装到 macOS 的 `~/Library/Application Support/Aholo-Rhino/usd-runtime` 或 Windows 的 `%LOCALAPPDATA%\Aholo-Rhino\usd-runtime`，不修改系统 Python。支持 `--wheel-dir 目录` 离线安装，或在启动 Rhino 前设置 `AHOLO_USD_PYTHON` 指向已有环境；安装之后导入导出完全在本机完成。详见 [USD 交换范围及验收](docs/usd-exchange.md)。

## 数据与隐私

后台使用专用标准输入/输出管道，实时预览另用当前用户专属、带每进程随机认证值的命名管道，没有本地 HTTP 控制端口。可选 OAuth 只在授权期间临时绑定系统选择的 IPv4 回环端口接收浏览器回调，之后关闭。只有该 Key 所属区域的固定 API 域名接收 Key；上传使用单独的短期 OUS 令牌，下载使用不带凭据的 HTTPS，并禁止重定向、检查目标为公网地址。

提交时，提示词、参考图或选中的渲染几何会发送至 Aholo。本地任务记录、输入快照和结果位于系统本地应用数据目录下的 `Aholo-Rhino`，导出目录可能留有中间 GLB。GS 导入会建立以 SHA-256 命名的 PLY 快照；Rhino 文档只保存哈希和本地路径，不嵌入全部高斯数据，转移 3dm 时需同时转移匹配的 PLY/缓存。资源缺失或变化时保留可见包围盒。因此文档可能包含本地文件路径。任务 JSON 不保存 Key 和带签名的资产 URL。断开连接会删除已保存 Key，保留本地工作。没有自动遥测。存储保护不防御同一用户权限下的其他进程或管理员。

本地资产库可搜索、分页浏览保留的全部记录，不再限于最近 100 条。实时清理日志保留原始会话标识，不保存 Key 或图像帧；JPEG 仅在内存中显示。关闭时会尝试服务端清理，但崩溃或网络失败可能留下需要处理的会话。上传阶段中断不会自动重启。大型导入/导出需要相应内存和磁盘空间。

GS 诊断日志写入本机 `Aholo-Rhino/logs/gs-viewport.log`，记录准备耗时、批次数和经过清理的错误；约 1 MiB 轮换并保留一份旧日志。`AholoGsDiagnostics` 会显示实际路径。日志不记录提示词、Key 或签名链接。

脚本使用新暂存目录构建平台候选包、校验归档并生成 SHA-256 记录，不会自动安装或发布。打上平台标签不代表已经完成该平台实机验收。

[架构与接口依据](docs/architecture.md) · [验证记录](docs/validation.md) · [宿主验收](docs/host-acceptance.md) · [官方接口快照](docs/api/README.md)

云预览 → **编辑云场景**可在开始前或运行中管理多个已入库的网格/GS 资产 ID，以及矩形灯和点灯。在独立草稿中添加、编辑或移除项目，再保存或应用；取消不会改变预览。模型可设置世界毫米坐标 XYZ 偏移、XYZ 旋转、统一及各轴比例、可选剪切与坐标约定。灯光可设置位置、线性 RGB、强度、尺寸及世界轴增量旋转，也可捕获选中的 Rhino 灯光而不修改文档。高级设置包含曝光、高光贡献、反射影响和矩形灯双面发光。零旋转保留捕获的方向，新矩形灯朝向局部 -Z；环境亮度为绝对正值倍率。

修改保持对象路径，并与相机更新共用顺序队列。只有服务端确认才提交本地场景，收到 JPEG 不代表确认。替换已有资产或类型必须添加新项目，已删除标识不可复用；编辑期间切换账号会拒绝过期草稿。结果不明时关闭原会话且不重发；服务端不保证多对象全部回退，也没有逐对象读回接口。云端删除和视觉效果仍待真实服务验收。镜像/剪切的云端效果及高级灯光开关仍待真实服务验收；原生混合深度合成仍未实现。详见[云场景编辑](docs/realtime-scene-editing.md)。

## OBJ 导入
