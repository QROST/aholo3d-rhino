# Contributing

Thank you for helping improve Aholo3D for Rhino.

For a bug, include a small reproducible example, expected behavior, Rhino/plugin versions and platform. Use synthetic or sanitized files. Never include credentials or private project data.

For code changes:

1. Discuss material API, data-format or compatibility changes in an issue.
2. Keep a pull request focused and describe the user-visible result.
3. Build and run the relevant checks in [development](docs/development.md).
4. Add regression coverage for changed behavior and update both language resources when needed.
5. Describe which native or live-service checks you actually performed.

Preserve plugin GUIDs, old document compatibility, task identity, uncertain-submission handling and original source assets. Do not add arbitrary geometry-count limits or silently convert unsupported content.

Contributions are made under the project's [Apache-2.0 license](LICENSE). Retain third-party notices and identify adapted code.
