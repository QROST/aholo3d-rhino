## Short description

Generate worlds and objects, view Gaussian scenes, and use Aholo3D cloud rendering in Rhino.

## Description

Aholo3D for Rhino brings World generation, Lux3D creation and local 3D tools into one workspace. Generate worlds from text/images, reconstruct supported photo or video inputs, create static models, and manage original task outputs in Library.

Import and view Gaussian PLY/SPZ/SPLAT scenes, place supported static meshes as native Rhino blocks with Undo, and exchange supported static mesh/GS scenes through USD/USDZ. Offline cloud rendering works from supported Rhino geometry; live cloud preview opens in a separate window.

Cloud features require an API Key for the selected International or China region and appropriate permissions/credits. Optional OAuth login does not replace that key. Local viewing and supported local imports can be used offline. USD exchange requires a separately installed runtime.

This preview includes experimental GS viewing. Native cloud depth compositing and animation playback are not supported. Latest-interface and Windows native acceptance remain pending.

An independent plugin by CuriousArc and qrost, not an official Aholo3D, Manycore or McNeel product. Run `Aholo3DPanel` after installation.
