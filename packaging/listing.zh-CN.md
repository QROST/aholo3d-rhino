## 简介

在 Rhino 中生成世界与模型、查看高斯场景，并使用 Aholo3D 云渲染。

## 介绍

Aholo3D for Rhino 将世界生成、Lux3D 创作和本地三维工具整合到一个工作区。通过文字或图片生成世界，使用支持的照片或视频重建，创建静态模型，并在资源库管理原始任务结果。

插件可导入和查看 PLY/SPZ/SPLAT 高斯场景，将受支持的静态网格以可撤销的 Rhino 块放入文档，并通过 USD/USDZ 交换受支持的静态网格、高斯与混合场景。离线云渲染可使用受支持的 Rhino 几何；实时云预览显示在独立窗口中。

云功能需要所选国际或中国区域的 API Key、相应权限和积分。可选 OAuth 登录不能替代 API Key。本地显示及受支持的本地导入可以离线使用；USD 交换需要另外安装运行时。

当前为预览版，GS 显示仍属实验功能。不支持原生云深度合成和动画播放；最新界面及 Windows 原生流程仍待验收。

由 CuriousArc 与 qrost 独立开发，并非 Aholo3D、Manycore 或 McNeel 官方产品。安装后运行 `Aholo3DPanel`。
